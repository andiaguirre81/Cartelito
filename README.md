# CARTELITO v3

Mobile Retro-Comic-Browsergame.

## Struktur
- `index.html` – komplettes Spiel
- `images/` – Aguirre-Games-Logo, Spielerportrait und einzelne Comic-Ereignisbilder

## Neu
- getrennte Bildschirme für Übersicht, Reisen, Mercado, Inventar und Preis-Historie
- nach einer Reise öffnet sich der Markt der Zielstadt
- 10 / 20 / 30 Tage
- BUY / SELL und Ø Einkaufspreis
- Comic-Ereignisse mit Padre Fuego, El Presidente, Hippie-Revolution, CIA, Policía und Straßenschießerei
- kleines Aguirre-Games-Branding und Home-Button
- mobil deutlich kompakter

## Home-Button
Im JavaScript steht oben `HOME_URL`. Er ist derzeit auf `https://andiaguirre81.github.io/` gesetzt und kann dort leicht geändert werden.

## Start
`index.html` öffnen oder den gesamten Inhalt in ein GitHub-Pages-Repository hochladen.
