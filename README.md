# CARTELITO – Business is Business

Kleines satirisches Retro-Browsergame im Geist klassischer 90er-Wirtschaftsspiele.

## Start
Einfach `index.html` im Browser öffnen.

## GitHub Pages
1. Neues Repository erstellen.
2. `index.html` ins Hauptverzeichnis hochladen.
3. Settings → Pages → Deploy from branch → main / root.
4. Fertig.

## Spielprinzip
- 30 Tage
- Zwischen fiktiven Städten reisen
- Fantasiewaren günstig kaufen und teuer verkaufen
- Zufallsereignisse
- Fahndungsstufen
- Charakter-/Rang-Aufstieg
- Mehrere Enden

Alle Orte, Ereignisse und Handelswaren sind satirisch/fiktiv.
